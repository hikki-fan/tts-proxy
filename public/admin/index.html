MiMo TTS HTTP Proxy

基于 MiMo TTS v2.5 API 的 HTTP 代理服务，为阅读类 App 提供 TTS 订阅源、音色管理、情感分析等功能。

模型支持：标准 · 声音设计 · 声音克隆 运行端口：3000

删除音色

删除后无法恢复，已上传的音频样本也将一并移除。

确认清空？

清空后将无法使用该服务，需重新填写 API Key 并保存。

获取 MiMo API Key

  1. 访问 MiMo 开放平台，注册或登录账号
  2. 进入控制台 → API Keys 页面
  3. 点击「创建密钥」，填写名称后确认
  4. 复制生成的密钥，粘贴到配置页的「MiMo API Key」输入框
前往 API Keys 页面 查看快速开始文档
